Production-grade automation suite for Proxmox VE 8.x+ and generic KVM/QEMU — covering every administrative task with Bash, Python, Go, Ansible, Terraform, and Packer, unified by a Go TUI application.
🎯 Project Purpose
Problem
Proxmox and KVM administration requires dozens of CLIs, APIs, and config files. No single tool covers the full lifecycle.
Solution
Unified automation suite with 340+ files, 6 languages, and a TUI that orchestrates everything from one binary.
Who uses this?
Sysadmins managing Proxmox clusters
DevOps engineers automating KVM hosts
Infrastructure teams at scale
Expected outcome
10x faster VM/CT provisioning
Zero-config cluster management
Single TUI for all operations

📌 Notes — Remember
⚠ Implementation Tips
Always run make lint before committing
Test with --dry-run on production clusters
Use config/settings.yaml over .env for team configs
Verify API tokens have least-privilege permissions
🔧 Deployment Notes
Requires Go 1.22+, Python 3.12+, Ansible 2.16+
TUI: make tui && ./bin/swissknife
Packer: install packer first, then make packer-build
Run make test after any changes
✅ Pro tip: Start with the TUI (swissknife) for day-to-day ops. Use Ansible playbooks for fleet-wide changes. Use Bash scripts for cron jobs and automation.
